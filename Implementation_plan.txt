## Task 6.1: Multi-Domain Scope Expansion (SaaS Mandates, Checkouts, B2B Invoices)

### Objective:
Satisfy the broad Track 3 mandate by supporting recurring subscription auto-debit retries, pre-payment checkout drop-offs, and overdue B2B receivables.

### 1. Database Schema (`packages/core/src/db/migrations/0016_domain_expansion.sql`):
```sql
-- 1. SaaS Recurring Subscription Mandates
CREATE TABLE IF NOT EXISTS subscription_mandates (
  id TEXT PRIMARY KEY,
  customer_id TEXT NOT NULL,
  customer_name TEXT,
  customer_phone TEXT,
  customer_email TEXT,
  mandate_type TEXT NOT NULL, -- 'UPI_AUTOPAY', 'E_NACH', 'CARD_RECURRING'
  plan_name TEXT NOT NULL,
  amount_paise INTEGER NOT NULL,
  last_failure_code TEXT,
  next_retry_at_utc TEXT,
  retry_sequence_count INTEGER DEFAULT 0,
  max_retries INTEGER DEFAULT 3,
  status TEXT DEFAULT 'ACTIVE', -- 'ACTIVE', 'RECOVERED', 'CANCELLED'
  created_at_utc TEXT NOT NULL
);

-- 2. Abandoned Pre-Payment Checkouts (Magic Checkout)
CREATE TABLE IF NOT EXISTS abandoned_checkouts (
  id TEXT PRIMARY KEY,
  customer_name TEXT,
  customer_phone TEXT NOT NULL,
  customer_email TEXT,
  cart_items_json TEXT,
  cart_amount_paise INTEGER NOT NULL,
  drop_off_step TEXT NOT NULL, -- 'PHONE_ENTERED', 'ADDRESS_SUBMITTED', 'PAYMENT_SCREEN_EXITED'
  recovery_token TEXT UNIQUE NOT NULL,
  status TEXT DEFAULT 'ABANDONED', -- 'ABANDONED', 'SALVAGED', 'EXPIRED'
  created_at_utc TEXT NOT NULL
);

-- 3. B2B Corporate Invoices & Receivables
CREATE TABLE IF NOT EXISTS b2b_invoices (
  id TEXT PRIMARY KEY,
  vendor_id TEXT NOT NULL,
  client_company TEXT NOT NULL,
  contact_person TEXT NOT NULL,
  contact_email TEXT NOT NULL,
  contact_phone TEXT,
  amount_paise INTEGER NOT NULL,
  invoice_number TEXT UNIQUE NOT NULL,
  due_date_utc TEXT NOT NULL,
  days_overdue INTEGER DEFAULT 0,
  early_discount_percent REAL DEFAULT 2.0, -- '2/10 Net 30'
  virtual_vpa TEXT,
  status TEXT DEFAULT 'OVERDUE', -- 'OVERDUE', 'PAID', 'DISCOUNT_APPLIED'
  created_at_utc TEXT NOT NULL
);
```

### 2. Backend API Handlers (`app/server.ts`):
* `POST /api/mandates/auto-debit-failure`:
  - Ingests recurring subscription failure (e.g. `INSUFFICIENT_FUNDS` on 1st of month).
  - Calculates optimal re-presentation window (e.g. 06:30 AM IST on salary day).
  - Dispatches proactive UPI Autopay pre-debit authorization notification via SMS.
* `POST /api/checkout/abandon`:
  - Captures customer phone/cart before payment is initiated.
  - Evaluates cart value: if $> ₹2,000$, schedules 1-tap cart salvage SMS with 15-minute price hold.
* `POST /api/invoices/chaser/initiate`:
  - Triggers automated B2B receivables workflow offering a 2% early settlement discount if paid within 48h via Razorpay Smart Collect Virtual Account.

## Task 6.2: Autonomous Dynamic Re-Planning Agent

### Objective:
Upgrade the decision layer from static timeline dunning to an active agent that perceives customer portal interactions and dynamically re-plans interventions.

### Implementation Blueprint (`packages/core/src/agent/recovery_agent.ts`):
```typescript
export interface CustomerInteractionEvent {
  eventId: string;
  interactionType: "SMS_DELIVERED" | "PORTAL_OPENED" | "PAYMENT_ATTEMPTED_FAILED" | "PORTAL_EXITED_NO_PAY";
  timeSinceFailureMinutes: number;
  openCount: number;
  nowMs: number;
}

export interface RePlanDecision {
  nextAction: ActionId;
  rationale: string;
  discountOfferPaise?: number;
  scheduledTimeUtc?: string;
}

export function evaluateDynamicRePlan(
  interaction: CustomerInteractionEvent,
  customerHistory: { isPaydayNear: boolean; orderAmountPaise: number }
): RePlanDecision {
  // 1. Customer clicked link multiple times but did not pay -> High intent, potential price barrier
  if (interaction.openCount >= 2 && interaction.interactionType === "PORTAL_EXITED_NO_PAY") {
    const downsellAmount = Math.round(customerHistory.orderAmountPaise * 0.90); // 10% instant salvage discount
    return {
      nextAction: "DOWNSELL_OFFER",
      discountOfferPaise: downsellAmount,
      rationale: "Agent perceived 2+ portal visits without payment. Injected 10% instant cart salvage concession.",
    };
  }

  // 2. Unopened after 2 hours -> Auto-escalate channel to WhatsApp
  if (interaction.interactionType === "SMS_DELIVERED" && interaction.timeSinceFailureMinutes >= 120) {
    return {
      nextAction: "RECOVER_WHATSAPP",
      rationale: "Agent perceived unopened SMS after 2 hours. Auto-switched channel to interactive WhatsApp recovery link.",
    };
  }

  // Default standard dunning sequence
  return {
    nextAction: "REMINDER_LINK",
    rationale: "Agent continuing standard multi-channel sequence.",
  };
}
```
